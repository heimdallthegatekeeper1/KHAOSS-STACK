# KHAOSS-STACK
KHAOSS Stack is short for Kanban, Hermes-Agent, AionUi, Obsidian, Space Agent, Screenpipe. Designed to do whatever your hearts desire is in AI loally and via cloude integration WITH PRIVACY SCRUBBING so you don't compromise data easily. Everything optional in the stack, I put a lot of work into this to eventually replace the stacks GUI with my own.
